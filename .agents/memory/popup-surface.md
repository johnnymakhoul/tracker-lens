---
name: Tracker Lens popup surface
description: Preferred presentation surface for the browser extension.
---

Tracker Lens should open from the browser toolbar in the current page's extension popup, not a separate tab. The popup is intentionally wider than the browser default so endpoint and cookie evidence remains readable.

**Why:** The user wants quick inspection without leaving the page being analyzed.

**How to apply:** Keep the action configured with an in-page popup and preserve the wide evidence-only layout when adding new evidence fields.
